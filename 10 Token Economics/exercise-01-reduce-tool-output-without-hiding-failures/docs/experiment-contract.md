# Experiment contract

The workload is fixed: Git history, repeated policy search, and the checkout tests. Modes are raw, rtk, and rtk-then-raw. A fallback is a second actual command and all its returned bytes count. The failing test must retain its nonzero exit and expose CHECKOUT-017 and checkout.test.mjs somewhere in the returned output. The scorer checks signal presence; a reviewer checks that the diagnosis is actually supported. Neither a green capture harness nor a compressed summary makes checkout healthy.

Adopt when afterBytes is less than beforeBytes and the required signals/exit codes survive; otherwise reject. UTF-8 bytes are the primary reproducible output measure. RTK estimates tokens from bytes, so do not call them provider token counts. A whole-session cost claim needs a separate matched agent experiment and provider usage, which this exercise does not require. Report any output detail the automated checks do not assess.
