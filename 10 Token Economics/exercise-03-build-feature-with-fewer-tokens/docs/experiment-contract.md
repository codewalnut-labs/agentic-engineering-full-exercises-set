# Experiment contract

Run three baseline and three assisted sessions, all from the original starter. The task is an exported service function, not an extra browser feature. A fresh temporary directory is used per session; the original requirements are identical. The runner keeps raw JSONL output, stderr, the invocation, the injected skill text, generated source/tests, and its independently replayed acceptance result. The standard reference path explicitly appends the supplied ponytail SKILL.md with --append-system-prompt-file, an instruction-loading technique documented by Claude Code. No claim of automatic activation is needed.

Total tokens = uncached input + cache writes + cache reads + output. Claude's reported output includes its billed generated tokens; do not add an invented reasoning estimate. Instruction overhead and repeated tool context are included in provider-reported totals. All three sessions in each lane count, even when their patches fail. Compare medians and ranges; also report summed list-price costs. Cached tokens are still tokens even when their input price is discounted.

Fresh agent sessions can share a provider's prompt cache. Keep all cached-token categories in the primary token total and report the cache breakdown when discussing secondary cost results. This experiment does not establish identical cache warmth or a causal dollar-saving estimate across all environments. Raw artifacts remain byte-exact; comparison of the selected source patch normalizes LF/CRLF so Git checkout settings do not create a false mismatch.

Adopt only if all three assisted trials pass the fixed correctness checks and assisted median total tokens is lower. Otherwise reject, even when a code diff is smaller. Choose one original successful assisted patch as the deliverable; selection does not remove other attempts from the measurements. A correct minimal baseline or no saving is a valid finding. Three trials of one task do not establish a general performance guarantee.
