# Feature Brief

Deliver the Team Invitations feature defined in the [approved specification](../../docs/invitation-contract.md).

The product decisions are supplied: who can invite, permitted roles, duplicate handling, expiry, one-time acceptance and revocation, unchanged state on rejection, and the required interface. Use the existing types, workspace policy, support incidents, and acceptance tests to guide implementation.

Use Superpowers to agree on the technical design, plan the work, implement with tests first, obtain independent code review, and verify the delivered feature. Preserve the product rules throughout the workflow.
